CPDAPN · Funded Network

CPDAPN API

Funded and leased business pricing for PBMs and commercial payers. Returns the CPDAPN price list for integrators operating under a funded network arrangement with Cost Plus Drugs.

Overview

CPDAPN (Cost Plus Drugs Access Pharmacy Network) is the funded / leased business channel for PBMs and commercial payers. Unlike CPD (mail order) and TCC (unfunded retail), CPDAPN pricing is structured for funded benefit plan arrangements.

CPDAPN channel data lives in the cpdapn_channel field on each PriceListEntry. This field is null for items not available on the CPDAPN channel.

Base URL https://api.costplusdrugs.com
Channel field cpdapn_channel
Use case PBMs · Commercial payers · Funded plans
Currency USD
ℹ️ The CPDAPN channel is intended for integrators operating under a funded network agreement. Contact Cost Plus Drugs if you need information about CPDAPN access or contracting.

GET /pricelist/cpdapn

Returns the full CPDAPN price list. Only cpdapn_channel is populated on each entry; cpd_channel and tcc_channel are omitted.

GET /pricelist/cpdapn
200 OK — PriceListEntry[] (cpdapn_channel only)

Supports the exclude_fields parameter. See Exclude Fields.

cURL 
curl -s https://api.costplusdrugs.com/pricelist/cpdapn

GET /pricelist/cpdapn/search

Search the CPDAPN price list by NDC, GPI, or term. Returns only entries with a cpdapn_channel. Supports the same parameters as /pricelist/search, including address for nearby funded-network pharmacy lookup.

GET /pricelist/cpdapn/search
200 OK — PriceListEntry[] (cpdapn_channel only)
cURL — CPDAPN-scoped search with pharmacy lookup 
curl -s "https://api.costplusdrugs.com/pricelist/cpdapn/search?ndc=00093-7424-56&address=233 S Wacker Dr, Chicago, IL 60606"
ℹ️ When an address is provided, cpdapn_channel.pharmacies is populated with nearby funded-network pharmacies (distinct from TCC unfunded pharmacies). Results are capped at 20 per drug entry, max 100-mile radius.

GET /pricelist/search

Search across all channels by NDC, GPI, or term. The cpdapn_channel field is populated when a matching CPDAPN entry exists.

GET /pricelist/search
200 OK — PriceListEntry[]
ℹ️ Provide at least one of ndc or term. See the full search parameter reference on the Overview page.

Query Parameters

ndc string · optional* National Drug Code (with or without dashes). Matches via equivalent_ndcs by default; use no_substitutions=true for exact matching.
no_substitutions boolean · optional Enforces exact-NDC matching. Requires ndc.
gpi string · optional Medispan GPI (with or without dashes). Ignored if ndc is provided.
term string · optional* Partial match against medication_name and brand_name. Ignored if ndc or gpi is provided.
strength string · optional Filter by dosage strength (e.g., 10mg). Requires term.
address string · optional Street address to populate cpdapn_channel.pharmacies with nearby funded-network pharmacies. Format: street, city, state, zip or zip code alone.
distance number · optional Search radius in miles. Defaults to 30. Maximum 100. Ignored if no address is provided. Results capped at 20 pharmacies per drug entry.
exclude_fields string · optional Comma-separated list of fields to exclude from the response.

Examples

cURL — Search by NDC 
curl -s "https://api.costplusdrugs.com/pricelist/search?ndc=00093-7424-56"
cURL — Search by GPI 
curl -s "https://api.costplusdrugs.com/pricelist/search?gpi=3900003010-2020"
cURL — Search by term, CPDAPN channel only 
curl -s "https://api.costplusdrugs.com/pricelist/search?term=metformin&exclude_fields=cpd_channel,tcc_channel"

Schema: CPDAPN Channel

The cpdapn_channel object returned on each PriceListEntry. Structurally identical to the TCC channel except there is no admin_fee and sample_pack_price_w_dispensing is calculated without it. All monetary values are in USD.

FieldTypeDescription
price_per_unit string USD per unit inclusive of CPD markup, formatted to 5 decimal places (e.g., "0.06667"). Use as the ingredient cost basis for PBM adjudication.
pharmacy_dispensing_fee number Standard CPDAPN dispensing fee (USD). May vary by chain — see pharmacies[].pharmacy_dispensing_fee for chain-specific values.
currency "USD" Always "USD".
sample_pack_price number price_per_unit × pack_size × ndc_count
sample_pack_price_w_dispensing number sample_pack_price + pharmacy_dispensing_fee — no admin fee, unlike the TCC channel.
pharmacies Pharmacy[] | omitted Nearby funded-network pharmacies. Present only when address is provided to a search endpoint. Capped at 20 results. See Pharmacy schema.
ℹ️ Dispensing fees and other adjudication components beyond those returned here are governed by your specific network contract.

Base Schema: PriceListEntry

The CPDAPN channel is returned alongside the standard PriceListEntry base fields. See the full PriceListEntry schema on the Overview page for all base fields including equivalent_ndcs, medication_name, strength, and more.

Key fields relevant to CPDAPN integrators:

FieldTypeDescription
external_sku string Stable external product identifier for cross-referencing.
equivalent_ndcs string[] All NDCs for which a generic equivalent can be provided. Used for claim matching without DAW=1.
pack_size number NDC package size from Medi-Span. Basis for quantity dispensed calculations.
splittable boolean Whether the pharmacy can dispense partial pack sizes.
cpdapn_channel object | null CPDAPN pricing. null if this drug is not available on the funded network.

Quick Reference

cURL — Full CPDAPN price list 
curl -s https://api.costplusdrugs.com/pricelist/cpdapn
cURL — Search by NDC (generic equivalent) 
curl -s "https://api.costplusdrugs.com/pricelist/search?ndc=00093-7424-56"

curl -s "https://api.costplusdrugs.com/pricelist/search?ndc=00093-7424-56&no_substitutions=true"

curl -s https://api.costplusdrugs.com/pricelist/all

curl -s "https://api.costplusdrugs.com/pharmacies/cpdapn?address=60606&distance=25"
