Pricing & Network API

Read-only endpoints for retrieving Direct-to-Consumer (CPD) and Team Cuban Card (TCC) price lists and searching by NDC or term, optionally localized by address for nearby pharmacies.

Overview

The Cost Plus Drugs Pricing and Network API provides programmatic access to our current drug price lists across three distribution channels. All endpoints are read-only and return JSON.

Use this API to:

  • Retrieve the full price list for any channel
  • Search by NDC (with or without generic substitutions), GPI, or drug name
  • Locate nearby TCC or CPDAPN pharmacies given a patient address
  • Fetch a single entry by external_sku

Server & Authentication

Base URL https://api.costplusdrugs.com
Protocol HTTPS only
Authentication None required
Response format application/json

Channels

Each drug listing may include pricing for one or more distribution channels. Use the dedicated channel endpoints for focused access, or /pricelist/all to retrieve everything at once.

Exclude Fields

All endpoints accept the query parameter exclude_fields, allowing callers to omit fields they don't need and reduce response size.

Pass a comma-separated list of field names. To exclude a nested field, use dot notation:

examples 
# Exclude the entire equivalent_ndcs array
exclude_fields=equivalent_ndcs

# Exclude a nested field inside cpd_channel
exclude_fields=cpd_channel.cash_dispensing_fee

# Exclude multiple fields
exclude_fields=equivalent_ndcs,tcc_channel,special_handling

GET /pricelist/all

Returns the complete price list with CPD and TCC channels populated where available. Note: CPDAPN pricing is not included in this endpoint — use /pricelist/cpdapn or /pricelist/search for funded-network pricing.

GET /pricelist/all
200 OK — PriceListEntry[] (cpd_channel + tcc_channel)
cURL 
curl -s https://api.costplusdrugs.com/pricelist/all

GET /pricelist/search

Search across all channels by NDC or drug name term. Optionally include a patient address to surface nearby TCC pharmacies.

GET /pricelist/search
200 OK — PriceListEntry[]
ℹ️ Provide at least one of ndc or term. If no_substitutions=true, ndc is required.

Query Parameters

ndc string · optional* National Drug Code (with or without dashes). Without no_substitutions=true, matches entries where equivalent_ndcs contains the NDC (generic-equivalent behavior). With no_substitutions=true, matches only entries stocking the exact NDC (DAW=1 equivalent).
no_substitutions boolean · optional When true, enforces exact-NDC match. Requires ndc; returns 400 if omitted.
gpi string · optional Medispan proprietary GPI (with or without dashes). Ignored if ndc is also provided.
term string · optional* Partial match across medication_name and brand_name. Ignored if ndc or gpi is provided.
strength string · optional Dosage strength (e.g., 10mg). Requires term. Ignored if ndc or gpi is provided.
address string · optional Street address to return nearby TCC pharmacies within 30 miles (or custom distance), sorted ascending. Format: street, city, state, zip. Omitted from response when not provided.
distance number · optional Search radius in miles. Defaults to 30. Maximum 100. Ignored if address is not provided.
external_sku string · optional Fetch a single entry by its stable external SKU. When provided, all other search parameters are ignored and the response is a single object (not an array).
exclude_fields string · optional Comma-separated list of fields to exclude. Use dot notation for nested fields.

Examples

cURL — Generic-equivalent by NDC 
curl -s "https://api.costplusdrugs.com/pricelist/search?ndc=00093-7424-56"
cURL — Exact NDC (no substitutions) 
curl -s "https://api.costplusdrugs.com/pricelist/search?ndc=00093-7424-56&no_substitutions=true"
cURL — Term search with address 
curl -s "https://api.costplusdrugs.com/pricelist/search?term=atorvastatin&address=233 S Wacker Dr, Chicago, IL 60606"

Error Responses

400 Bad Request
JSON 
{
  "error": "ndc is required when asking for no substitutions"
}
JSON — missing search params 
{
  "error": "search parameters must be added to the query string"
}

Schema: PriceListEntry

Base object returned by all list and search endpoints. Channel-specific pricing is nested under cpd_channel, tcc_channel, or cpdapn_channel. A field is null or omitted when the item is not available in that channel.

Field Type Required Description
external_sku string Yes Stable external SKU identifier.
medication_name string Yes Medication display name (generic or brand).
brand_generic "Generic" | "Branded" Yes Drug classification.
form string Yes Dosage form (e.g., Tablet).
strength string Yes Strength (e.g., 20 mg).
brand_name string Yes For generics, the brand this maps to; for brands, itself.
pack_size number Yes Numeric NDC pack size (Medi-Span). If splittable=false, dispensing is in multiples of this.
quantity number Yes Number of packs (from Medi-Span).
unit string Yes Unit of measure (e.g., tablets, mL).
splittable boolean Yes true if a pharmacy can dispense less than the full pack_size; false if only multiples of pack_size are available.
equivalent_ndcs string[] Yes All NDCs for which a generic equivalent can be provided.
url string | null Conditional URL for the product listing at costplusdrugs.com. Present for CPD entries; null for TCC-only entries. Omitted entirely when the response excludes cpd_channel.
special_handling string | null No Special handling designation. Value is "cold-chain" when applicable; null otherwise.
sample_pack_size number No Default 30 for pills.
sample_volume string No Human-readable sample size (e.g., 30 tablets).
treatment_categories string[] No Readable indications and categories for the medication.
cpd_channel object | null No CPD pricing and availability. See CPD channel schema.
tcc_channel object | null No TCC pricing, fees, and pharmacies. See TCC channel schema.
cpdapn_channel object | null No CPDAPN (funded) pricing. See CPDAPN channel schema.

Schema: SamplePricing

Pricing calculated for multiple dispense quantities. Always three entries: 1×, 2×, and 3× the default sample pack size (typically 30, 60, 90 for splittable pills; 1, 2, 3 units for non-splittable). All price fields are returned as decimal strings (e.g., "2.10").

FieldTypeDescription
sample_pack_size string e.g., "30 count", "60 count", "1 Tablet".
sample_pack_price string sample_pack_size × price_per_unit, formatted to 2 decimal places.
sample_pack_price_total_to_patient_without_shipping string sample_pack_price + dispensing_fee, formatted to 2 decimal places.

Additional Endpoints

Beyond the primary list and search endpoints, the API exposes several focused endpoints.

Channel-scoped search

Each channel has a dedicated search endpoint that returns results filtered to that channel only:

cURL
GET /pricelist/cpd/search?ndc=00093-7424-56
GET /pricelist/tcc/search?term=atorvastatin
GET /pricelist/cpdapn/search?ndc=00093-7424-56

Accept the same query parameters as /pricelist/search (ndc, term, gpi, strength, no_substitutions, address, distance, exclude_fields). The TCC and CPDAPN scoped search endpoints also support the address parameter for pharmacy lookup.

GET /pricelist/fetch

Fetch a single entry by external_sku. Returns the matching object or undefined.

cURL
curl -s "https://api.costplusdrugs.com/pricelist/fetch?external_sku=942206fffceea95d4c8393c77ea617ab"

GET /pharmacies/tcc

Returns all TCC (unfunded) network pharmacies. Accepts optional address and distance (max 100 miles) to filter to a geographic area.

cURL
curl -s "https://api.costplusdrugs.com/pharmacies/tcc?address=233 S Wacker Dr, Chicago, IL 60606&distance=10"

GET /pharmacies/cpdapn

Returns all CPDAPN (funded) network pharmacies. Same parameters as /pharmacies/tcc.

cURL
curl -s "https://api.costplusdrugs.com/pharmacies/cpdapn?address=60606&distance=25"

GET /pricelist/cpd/simplified

Returns a marketing-friendly flat list of CPD entries. Each item includes a human-readable price string rather than raw fee components. Returns three entries per drug (30-count, 60-count, 90-count or equivalent).

cURL
curl -s https://api.costplusdrugs.com/pricelist/cpd/simplified

Sample item:

JSON
{
  "medication_name": "Atorvastatin",
  "brand_generic": "Generic",
  "brand_name": "Lipitor",
  "strength": "20 mg",
  "form": "Tablet",
  "price": "30 count of Atorvastatin 20 mg costs $7.10. This does not include shipping.",
  "in_stock": true,
  "special_handling": "",
  "url": "https://www.costplusdrugs.com/medications/atorvastatin-20mg-tablet/",
  "equivalent_ndcs": ["00093-7424-56"],
  "treatment_categories": ["Cardiovascular"]
}

Business Rules

  • Provide at least one of ndc or term for /pricelist/search.
  • no_substitutions=true requires ndc and enforces exact-NDC matching.
  • If address is provided, tcc_channel.pharmacies and cpdapn_channel.pharmacies are populated with nearby pharmacies (default 30-mile radius, max 100 miles), sorted ascending by distance, capped at 20 results.
  • If a drug is excluded for a pharmacy chain, that chain will not appear in pharmacy results for that drug.
  • /pricelist/all returns CPD + TCC only. CPDAPN is available via /pricelist/cpdapn or /pricelist/search.
  • CPD: sample_pack_price_w_shipping_dispensing = sample_pack_price + shipping_cost + dispensing_fee
  • TCC: sample_pack_price_w_dispensing = sample_pack_price + pharmacy_dispensing_fee + admin_fee
  • CPDAPN: sample_pack_price_w_dispensing = sample_pack_price + pharmacy_dispensing_fee (no admin fee)
  • Some pharmacy chains have chain-specific dispensing fees. Always use pharmacies[].sample_pack_price_w_dispensing for patient-facing totals.
