TCC API

Team Cuban Card — unfunded retail pharmacy network. Returns pricing, dispensing fees, and optionally nearby TCC pharmacies when a patient address is provided.

Overview

TCC (Team Cuban Card) is an unfunded retail pharmacy network. Patients fill their prescriptions at participating local pharmacies at Cost Plus Drugs prices. Unlike CPD, there is no mail-order fulfillment — the patient picks up at a pharmacy.

TCC channel data lives in the tcc_channel field on each PriceListEntry. When an address is provided during a search, the tcc_channel.pharmacies array is populated with nearby pharmacies sorted by distance. If no address is provided, pharmacies is omitted.

Base URL https://api.costplusdrugs.com
Channel field tcc_channel
Fulfillment Retail pharmacy pick-up
Pharmacy radius Default 30 miles · max 100 miles · capped at 20 results per drug
Currency USD
ℹ️ If a TCC product is excluded by a pharmacy chain, that chain's locations will not appear in the pharmacy results, even if they are within the search radius.

GET /pricelist/tcc

Returns the full TCC price list. Only tcc_channel is populated on each entry. The pharmacies array is omitted — use /pricelist/search with an address to include pharmacy locations.

GET /pricelist/tcc
200 OK — PriceListEntry[] (tcc_channel only, no pharmacies)

Supports the exclude_fields parameter. See Exclude Fields.

cURL 
curl -s https://api.costplusdrugs.com/pricelist/tcc

GET /pricelist/tcc/search

Search TCC prices by NDC, GPI, or term. Returns only entries with a tcc_channel. Accepts the same query parameters as /pricelist/search, including address for pharmacy geo-lookup.

GET /pricelist/tcc/search
200 OK — PriceListEntry[] (tcc_channel only)
cURL — TCC-scoped NDC search with pharmacies 
curl -s "https://api.costplusdrugs.com/pricelist/tcc/search?ndc=00093-7424-56&address=233 S Wacker Dr, Chicago, IL 60606"

GET /pricelist/search

Search by NDC or term. When an address is included, tcc_channel.pharmacies is populated with nearby locations sorted by distance.

GET /pricelist/search
200 OK — PriceListEntry[]
ℹ️ Provide at least one of ndc or term. Adding an address enables pharmacy geo-lookup.

Query Parameters

ndc string · optional* National Drug Code (with or without dashes). Matches entries where equivalent_ndcs contains the NDC (generic substitution) unless no_substitutions=true.
no_substitutions boolean · optional When true, enforces exact-NDC matching. Requires ndc.
gpi string · optional Medispan GPI. Ignored if ndc is provided.
term string · optional* Partial match against medication_name and brand_name. Ignored if ndc or gpi is provided.
strength string · optional Filter by dosage strength (e.g., 10mg). Requires term.
address string · optional Patient street address. When provided, populates tcc_channel.pharmacies with nearby TCC pharmacies sorted by ascending distance.
Format: street, city, state, zip (e.g., 233 S Wacker Dr, Chicago, IL 60606)
distance number · optional Search radius in miles. Defaults to 30. Maximum 100. Ignored if no address is provided. Pharmacy results are capped at 20 per drug entry.
exclude_fields string · optional Comma-separated list of fields to exclude.

Examples

cURL — Term search with nearby pharmacies 
curl -s "https://api.costplusdrugs.com/pricelist/search?term=atorvastatin&address=233 S Wacker Dr, Chicago, IL 60606"
cURL — NDC search with 10-mile pharmacy radius 
curl -s "https://api.costplusdrugs.com/pricelist/search?ndc=00093-7424-56&address=233 S Wacker Dr, Chicago, IL 60606&distance=10"
cURL — Exclude TCC pharmacies from response 
curl -s "https://api.costplusdrugs.com/pricelist/search?term=metformin&exclude_fields=tcc_channel.pharmacies"

Schema: TCC Channel

The tcc_channel object returned on each PriceListEntry. All monetary values are in USD. pharmacies is only present when an address is supplied to search.

FieldTypeDescription
price_per_unit string USD per unit inclusive of CPD markup, formatted to 5 decimal places (e.g., "0.06667").
pharmacy_dispensing_fee number Standard TCC dispensing fee (USD). Some chains (e.g., Walgreens) have a different fee — see pharmacies[].pharmacy_dispensing_fee.
currency "USD" Always "USD".
admin_fee number Admin fee (USD). Included in sample_pack_price_w_dispensing. Not present on the CPDAPN channel.
sample_pack_price number price_per_unit × pack_size × ndc_count
sample_pack_price_w_dispensing number sample_pack_price + pharmacy_dispensing_fee + admin_fee
pharmacies Pharmacy[] | omitted Nearby pharmacies. Only present when address is provided. Capped at 20 results. Sorted by ascending distance. Pharmacies that exclude this specific TCC product are filtered out.

Schema: Pharmacy

One entry per participating pharmacy within the search radius, nested under tcc_channel.pharmacies.

FieldTypeRequiredDescription
name string Yes Pharmacy name (e.g., Walgreens, Community Pharmacy).
npi string Yes National Provider Identifier.
chain_code string No Chain code if the pharmacy is part of a chain.
address string Yes Full pharmacy address.
distance string Yes Approximate miles from the search address, formatted to 2 decimal places (e.g., "0.60").
pharmacy_dispensing_fee number Yes Chain-specific dispensing fee. For most pharmacies this equals tcc_channel.pharmacy_dispensing_fee; some chains (e.g., Walgreens) may differ.
sample_pack_price_w_dispensing number Yes Total cost at this specific pharmacy using its own dispensing fee. Always use this field for patient-facing price display.
address_obj object Yes Structured address. Fields: line, line2, city, state, postal_code.
chain string Yes Chain name identifier (e.g., "WAG" for Walgreens).
phone_number string Yes Pharmacy phone number.
effective_date string Yes Network effective date for this pharmacy location.

Pricing Formulas

Standard TCC Total

Formula 
patient_total = (sample_pack_size × price_per_unit)
              + pharmacy_dispensing_fee
              + admin_fee

Chain-Specific Total

When displaying pricing at a specific pharmacy, substitute that pharmacy's fee:

Formula 
patient_total_at_chain = (sample_pack_size × price_per_unit)
                        + pharmacies[i].pharmacy_dispensing_fee
                        + admin_fee

# Or use the pre-computed field directly:
patient_total_at_chain = pharmacies[i].sample_pack_price_w_dispensing
