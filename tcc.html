TCC API

Team Cuban Card — unfunded retail pharmacy network. Returns pricing, dispensing fees, and optionally nearby TCC pharmacies when a patient address is provided.

Overview

TCC (Team Cuban Card) is an unfunded retail pharmacy network. Patients fill their prescriptions at participating local pharmacies at Cost Plus Drugs prices. Unlike CPD, there is no mail-order fulfillment — the patient picks up at a pharmacy.

TCC channel data lives in the tcc_channel field on each PriceListEntry. When an address is provided during a search, the tcc_channel.pharmacies array is populated with nearby pharmacies sorted by distance. If no address is provided, pharmacies is omitted.

Base URL https://api.costplusdrugs.com
Channel field tcc_channel
Fulfillment Retail pharmacy pick-up
Pharmacy radius Default 30 miles · max 100 miles · capped at 20 results per drug
Currency USD
ℹ️ Only TCC network pharmacies are returned. Chains that participate only in the funded network (e.g., Walgreens) appear in CPDAPN results, never TCC. If a TCC product is excluded by a pharmacy chain, that chain's locations will not appear in the pharmacy results for that product, even if they are within the search radius.

GET /pricelist/tcc

Returns the full TCC price list. Only tcc_channel is populated on each entry. The pharmacies array is omitted — use /pricelist/tcc/search with an address to include pharmacy locations.

GET /pricelist/tcc
200 OK — PriceListEntry[] (tcc_channel only, no pharmacies)

Supports the exclude_fields and treatment_category parameters. See Exclude Fields and Treatment Category Filter.

cURL 
curl -s https://api.costplusdrugs.com/pricelist/tcc

GET /pricelist/tcc/search

Search TCC prices by NDC, GPI, or term. Returns only entries with a tcc_channel. Accepts the same query parameters as /pricelist/tcc, including address for pharmacy geo-lookup.

GET /pricelist/tcc/search
200 OK — PriceListEntry[] (tcc_channel only)
cURL — TCC-scoped NDC search with pharmacies 
curl -sG https://api.costplusdrugs.com/pricelist/tcc/search \
  -d ndc=67877-0511-10 \
  --data-urlencode "address=233 S Wacker Dr, Chicago, IL 60606"
cURL — Custom quantity (45 tablets) with pharmacies 
curl -sG https://api.costplusdrugs.com/pricelist/tcc/search \
  -d ndc=67877-0511-10 \
  -d units=45 \
  --data-urlencode "address=233 S Wacker Dr, Chicago, IL 60606"

Also accepts units or packs to price a specific amount; see Custom Quantity Pricing.

Schema: TCC Channel

The tcc_channel object returned on each PriceListEntry. All monetary values are in USD. pharmacies is only present when an address is supplied to search.

FieldTypeDescription
price_per_unit string USD per unit inclusive of CPD markup, formatted to 5 decimal places (e.g., "0.06667").
pharmacy_dispensing_fee number Standard TCC dispensing fee (USD). Pharmacy-specific fees, when present, are in pharmacies[].pharmacy_dispensing_fee.
currency "USD" Always "USD".
admin_fee number Admin fee (USD). Included in sample_pack_price_w_dispensing. Not present on the CPDAPN channel.
sample_pack_price number price_per_unit × pack_size × ndc_count
sample_pack_price_w_dispensing number sample_pack_price + pharmacy_dispensing_fee + admin_fee
pharmacies Pharmacy[] | omitted Nearby TCC network pharmacies. Only present when address is provided. The nearest 20 within the search radius, sorted by ascending distance. Pharmacies outside the TCC network, or that exclude this specific TCC product, are filtered out before the 20 are selected.
requested_quantity_pricing object | omitted Only present when units or packs is passed to a search endpoint and the amount is valid for this product. Fields: units (number), price (number, units × price_per_unit), price_w_dispensing (number, price + pharmacy_dispensing_fee + admin_fee). See Custom Quantity Pricing.

Schema: Pharmacy

One entry per participating pharmacy within the search radius, nested under tcc_channel.pharmacies (and cpdapn_channel.pharmacies on CPDAPN searches). /pharmacies/tcc and /pharmacies/cpdapn return the same fields except the drug-specific pharmacy_dispensing_fee and sample_pack_price_w_dispensing, and include distance only when an address is given.

FieldTypeRequiredDescription
name string Yes Pharmacy name (e.g., Osco Pharmacy, Printer's Row Pharmacy).
npi string Yes National Provider Identifier.
chain_code string | null No Numeric chain code (e.g., "156") if the pharmacy is part of a chain; null for independents.
address string Yes Full pharmacy address.
distance string Yes Approximate miles from the search address, formatted to 2 decimal places (e.g., "0.60").
pharmacy_dispensing_fee number Yes Pharmacy-specific dispensing fee. For most pharmacies this equals the channel's pharmacy_dispensing_fee; some chains differ (e.g., Walgreens on the CPDAPN network).
sample_pack_price_w_dispensing number Yes Total cost at this specific pharmacy using its own dispensing fee. Always use this field for patient-facing price display.
requested_quantity_price_w_dispensing number Conditional Same as sample_pack_price_w_dispensing, but for the amount requested with units or packs. Only present when one was passed and is valid for the product. Includes the admin fee on TCC; never on CPDAPN.
address_obj object Yes Structured address. Fields: line, line2, city, state, postal_code.
chain string Yes Chain name identifier (e.g., "Albertsons", "Kroger", "Independent"; "WAG" for Walgreens, CPDAPN only).
phone_number string | null No Pharmacy phone number, when available.
effective_date string Yes Network effective date for this pharmacy location.

Pricing Formulas

Standard TCC Total

Formula 
patient_total = (sample_pack_size × price_per_unit)
              + pharmacy_dispensing_fee
              + admin_fee

Chain-Specific Total

When displaying pricing at a specific pharmacy, substitute that pharmacy's fee:

Formula 
patient_total_at_chain = (sample_pack_size × price_per_unit)
                        + pharmacies[i].pharmacy_dispensing_fee
                        + admin_fee

# Or use the pre-computed field directly:
patient_total_at_chain = pharmacies[i].sample_pack_price_w_dispensing
