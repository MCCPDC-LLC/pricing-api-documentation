# Cost Plus Drugs — Pricing & Network API Documentation

Static documentation site for the CPD Pricing and Network API. Deployed via GitHub Pages.

## Pages

| Page | URL | Description |
|------|-----|-------------|
| Overview | `/index.html` | API overview, shared schemas, `/pricelist/all`, search parameters |
| CPD | `/cpd.html` | Mail-order pharmacy — cash & insurance pricing |
| TCC | `/tcc.html` | Team Cuban Card retail network — pharmacy geo-lookup |
| CPDAPN | `/cpdapn.html` | Funded / leased PBM network pricing |

## Deploying

Push to `main` or `master` — GitHub Actions deploys automatically to GitHub Pages.

To enable Pages on a new repo: **Settings → Pages → Source → GitHub Actions**.
