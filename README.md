# Cost Plus Drugs — Pricing & Network API Documentation

Static documentation site for the CPD Pricing and Network API. Deployed via GitHub Pages.

**Live site:** https://mccpdc-llc.github.io/pricing-api-documentation/

## Pages

| Page | URL | Description |
|------|-----|-------------|
| Overview | https://mccpdc-llc.github.io/pricing-api-documentation/ | API overview, shared schemas, `/pricelist/all`, search parameters |
| CPD | https://mccpdc-llc.github.io/pricing-api-documentation/cpd.html | Mail-order pharmacy — cash & insurance pricing |
| TCC | https://mccpdc-llc.github.io/pricing-api-documentation/tcc.html | Team Cuban Card retail network — pharmacy geo-lookup |
| CPDAPN | https://mccpdc-llc.github.io/pricing-api-documentation/cpdapn.html | Funded / leased PBM network pricing |

## Deploying

Push to `main` or `master` — GitHub Actions deploys automatically to GitHub Pages.

To enable Pages on a new repo: **Settings → Pages → Source → GitHub Actions**.
